## Highlights

- **Bilingual** — Arabic (RTL) by default with an instant English switch
- **Sections** — home, about, objectives, services, fleet, why us, trust and certifications (ISO), contact
- **Responsive** — mobile menu, back-to-top button, works from phone to desktop
- **Zero dependencies** — a single self-contained `index.html` (styles and scripts inline), so it deploys to any static host

## Run locally

No build step — open `index.html`, or serve the folder:

```bash
python3 -m http.server 8000
# http://localhost:8000
```
